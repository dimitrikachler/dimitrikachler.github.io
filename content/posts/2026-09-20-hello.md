## Writing a new post

Create a file in `content/posts/` named `YYYY-MM-DD-some-slug.md`, give it a
front matter block, and write. The build script picks it up, sorts it by date,
and generates the list page.

```bash
cp content/posts/2026-09-20-hello.md content/posts/2026-10-01-my-idea.md
python3 build.py            # writes _site/
python3 -m http.server -d _site 8000
```

Set `draft: true` in the front matter to keep a post out of the build.

## What Markdown you get

Headings, **bold**, *italic*, `inline code`, [links](https://arxiv.org),
bullet and numbered lists, block quotes, images, horizontal rules and fenced
code blocks.

> Quotes look like this. Useful for the one sentence from a paper that the
> whole post is arguing with.

Math works through KaTeX, inline like $\nabla_\theta \mathcal{L}(\theta)$ and
as a display block:

$$
\mathcal{I}(z, z_{\text{test}}) = -\nabla_\theta L(z_{\text{test}})^\top H_\theta^{-1} \nabla_\theta L(z)
$$

That is the whole system. No Ruby, no npm, no dependencies.
